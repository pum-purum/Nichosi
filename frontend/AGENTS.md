# Frontend (Svelte + TypeScript)

- Используйте Svelte, Vite и TypeScript в строгом режиме. Первый шаг создания приложения — `npm create vite@latest . -- --template svelte-ts`, затем добавьте зависимости.
- Типы API генерируются командой `make types` в `src/lib/api/schema.d.ts`. Используйте тонкий типизированный клиент, например openapi-fetch. Не описывайте вручную типы объектов контракта.
- Работайте через `make mock` (Prism на порту `:4010`); позднее переключите прокси разработки на реальный backend.
- Библиотеки: CodeMirror 6 для SQL-редактора, Cytoscape.js для графа связей, виртуализированная таблица (собственная небольшая реализация или поддерживаемая библиотека; проверьте лицензию).
- Следуйте оригинальному визуальному направлению из `../docs/design/README.md`. Не используйте интерфейс, фирменный стиль или изображения других продуктов как образец.
- Тема задаётся CSS-переменными на `:root`; в первую очередь поддерживайте тёмную тему.
- Состояние храните в Svelte stores. Изменения ячеек накапливаются в ChangeSet store; Apply отправляет весь набор изменений.
- Доступность: навигация по таблице с клавиатуры, видимый фокус, значение не должно передаваться только цветом.
- Необходимые скрипты: `dev`, `build`, `check`, `test`.

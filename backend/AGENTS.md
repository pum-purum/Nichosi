# Backend (Go)

- В первую очередь используйте стандартную библиотеку Go: `net/http` с маршрутизатором по шаблонам Go 1.22+, `log/slog` и `context` во всех подходящих местах.
- Драйверы: `go-sql-driver/mysql`, `pgx`, `modernc.org/sqlite` (без cgo).
- Типы и заглушки сервера генерируются из `../api/openapi.yaml` с помощью oapi-codegen. Сверяйтесь с актуальной документацией по его параметрам. Не пишите вручную типы запросов и ответов, уже определённые контрактом.
- Структура:
  - `cmd/nichosi` — точка входа; чтение конфигурации из окружения и сборка зависимостей.
  - `internal/driver` — интерфейс `Driver` и реализации для диалектов; ВЕСЬ SQL для конкретных диалектов должен находиться здесь.
  - `internal/service` — ConnService, SchemaService, DataService, RelationService, StatsService и ChangeSet.
  - `internal/httpapi` — HTTP-обработчики, middleware аутентификации и преобразование ошибок.
  - `internal/store` — локальная SQLite: профили, история, ручные связи, кэш статистики и зашифрованные секреты.
- Конфигурация через переменные окружения: `NICHOSI_ADDR` (по умолчанию `127.0.0.1:8080`), `NICHOSI_ADMIN_TOKEN`, `NICHOSI_CONNECTIONS_FILE`, `NICHOSI_LOCAL_PREVIEW`. Файлы `.env` автоматически не загружаются. Для интеграционных тестов используется `NICHOSI_TEST_DSN`.
- Привязка к `0.0.0.0` должна быть явным выбором. До привязки к адресу, отличному от loopback, требуется аутентификация администратора.
- Оборачивайте ошибки с `%w`; преобразуйте их в схему `Error` из контракта только на HTTP-границе.
- Пишите табличные тесты. Интеграционные тесты используют только локальную тестовую базу разработчика и должны пропускаться, если она недоступна.
